# Regional Exceptions

Certain regions historically tolerate list prices 5-10% above the
national reference price without the usual volume-loss alarms -- tourist
and coastal regions in particular, where demand is more seasonal and less
price-sensitive than the national average.

Note for the pricing engine: this policy is documented for when regional
data is available, but the current demand model and optimizer are
national-level only -- there is no region field in the panel data, so
this exception is not yet enforced anywhere in the system. Treat any
copilot answer that cites this file as a flag for a manual regional
review, not as something the optimizer already accounted for.
